Optical components ​

Optical elements serve as the building blocks for optical systems in the context of this package, representing components such as mirrors, lenses, filters and so on. A collection of basic optical elements is provided with this package as is. They are tested for the correctness of their optical interactions and are verified to work with reasonable fidelity. Browse the catalog below, or refer to the Mirrors, Lenses, Prisms, Beamsplitters, Detectors and Polarizers pages for detailed documentation.

Passive objects ​

Two objects have no optical effect of their own and are built from a shape, e.g. a Mesh loaded from a file:

  • IntersectableObject is hit by beams and blocks them like a hard target, e.g. a beam dump or a housing wall.

  • NonInteractableObject is never hit: beams pass through it as if it was not there. It is meant for visualization, e.g. kinematic mounts, and can be moved with the kinematic functions like any other component.

Moving components ​

Optical elements can be moved freely in 3D space and combined into groups that move as one, see Moving optical elements in the Kinematics section.

Inspecting components ​

BeamletOptics.properties lists what a component stores as name => value pairs, e.g. its type, pose, shape and optical parameters. Values are SI numbers; the unit is given in brackets at the end of the name, names without brackets are dimensionless. It also works for shapes, beams and sources. Tools such as the inspector of the BeamletOpticsGUI live view display this list.

julia
lens = SphericalLens(50e-3, -50e-3, 5e-3, 25.4e-3)
BeamletOptics.properties(lens)            # e.g. "Type" => "Lens", "Position [m]" => [0.0, 0.0, 0.0], ...
1
2

A new AbstractObject subtype gets the BeamletOptics.default_properties (type, pose and shape) without further work; a method of properties for the subtype adds its own parameters.

BeamletOptics.properties Function
julia
properties(x) -> Vector{Pair{String, Any}}
1

Returns the properties of x (an AbstractObject, shape, beam, source or object group) as a list of name => value pairs for display, e.g. in the inspector of the GUI package BeamletOpticsGUI. Only stored or cheaply derived values are listed, e.g. the reflectance of a beamsplitter (the power ratio R, as passed to its constructor) or the number of hits of a Detector, no design parameters that the object does not store. The list is computed on each call, i.e. it shows the current pose and hits.

Conventions

  • values are numbers in SI units, vectors of them (e.g. a position), Strings or Bools

  • the unit of a value is given in brackets at the end of its name, e.g. "Diameter [m]" or "Angle [rad]"; names without brackets are dimensionless, e.g. "Reflectance"

  • the list starts with default_properties: "Type", the pose and, for objects, the shape

julia
julia> BeamletOptics.properties(SphericalLens(50e-3, -50e-3, 5e-3, 25.4e-3))

Custom components

Add a method for your type that extends the default list, e.g.

julia
BeamletOptics.properties(x::MyFilter) =
    [BeamletOptics.default_properties(x); "Optical density" => x.od; "Center wavelength [m]" => x.λc]
1
2

Without a method, default_properties is shown.

source
BeamletOptics.default_properties Function
julia
default_properties(x) -> Vector{Pair{String, Any}}
1

Returns the properties that properties lists for any object, shape, beam, source or object group x, see its conventions:

  • "Type": the name of the type of x

  • depending on the BeamletOptics.AbstractKinematicTrait of x: "Position [m]" and "Optical axis" (local +y axis) for oriented objects, "Position [m]" and "Direction" for directed ones (beams), only "Position [m]" for static objects

  • for an AbstractObject, depending on its BeamletOptics.AbstractShapeTrait: the properties of its shape ("Shape" and the stored dimensions, e.g. "Diameter [m]") or the number of its "Parts"

  • for an object group: the number of its objects as "Parts"

Methods of properties for specific types start from this list, see properties.

source

Own components

The geometry of a component lives in its shape, its optical effect in its BeamletOptics.interact3d method. To add a component of your own, see Implementing components for the functions a solve calls on an object and how the component families react to a hit.
