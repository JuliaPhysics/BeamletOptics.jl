Optical components ​

Optical elements serve as the building blocks for optical systems in the context of this package, representing components such as mirrors, lenses, filters and so on. A collection of basic optical elements is provided with this package as is. They are tested for the correctness of their optical interactions and are verified to work with reasonable fidelity. Browse the catalog below, or refer to the Mirrors, Lenses, Beamsplitters, Detectors and Polarizers pages for detailed documentation.

Moving components ​

Optical elements can be moved freely in 3D space and combined into groups that move as one, see Moving optical elements in the Kinematics section.

Listing available components ​

When using this package in the REPL, a tree view of all implemented BeamletOptics.AbstractObjects can be generated via the BeamletOptics.list_subtypes helper function. Note that this function is not able to determine all available constructors.

julia
julia> BeamletOptics.list_subtypes(BeamletOptics.AbstractObject);
└── BeamletOptics.AbstractObject
    ├── BeamletOptics.AbstractBeamsplitter{T} where T<:Real
    │   ├── BeamletOptics.AbstractPlateBeamsplitter{T} where T<:Real
    │   │   ├── RectangularPlateBeamsplitter{T} where T<:Real
    │   │   └── RoundPlateBeamsplitter{T} where T<:Real
    │   ├── CubeBeamsplitter{T} where T<:Real
    │   └── ThinBeamsplitter
    ├── BeamletOptics.AbstractDetector{T} where T<:Real
    │   └── Detector{T, S} where {T<:Real, S<:BeamletOptics.AbstractShape{T}}
    ├── BeamletOptics.AbstractJonesPolarizer{T} where T<:Real
    │   └── PolarizationFilter{T, S} where {T<:Real, S<:BeamletOptics.AbstractShape{T}}
    ├── BeamletOptics.AbstractObjectGroup{T} where T<:Real
    │   └── ObjectGroup{T} where T<:Real
    ├── BeamletOptics.AbstractReflectiveOptic{T} where T<:Real
    │   ├── Mirror{T, S} where {T<:Real, S<:BeamletOptics.AbstractShape{T}}
    │   └── Retroreflector{T} where T<:Real
    ├── BeamletOptics.AbstractRefractiveOptic{T} where T<:Real
    │   ├── Lens{T, S} where {T<:Real, S<:BeamletOptics.AbstractShape{T}}
    │   └── Prism{T, S} where {T<:Real, S<:BeamletOptics.AbstractShape{T}}
    ├── DoubletLens{T, F, B} where {T<:Real, F<:BeamletOptics.AbstractShape{T}, B<:BeamletOptics.AbstractShape{T}}
