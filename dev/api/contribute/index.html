Contributing

While not strictly adhering to the SciML Style Guide, we recommend consulting the guide as a baseline for contributions to this package. Refer to the SciML Contributors Guide as well. Ideally, your contribution features:

  • tests for new or changed functionality
  • docstrings for relevant functions
  • documentation and examples

We would also love to feature your work with this package as part of the Examples section.
