API design ​

This part of the documentation is intended for users that want to change the internals of BMO. You can develop the package locally by typing ] dev BeamletOptics in the REPL. An overview of all relevant topics is provided below. The following sections assume that you are in principle familiar with the concept of rays and beams, as well as optical elements – e.g. mirrors – in the context of this package. If not, it is recommended that you read the Rays, Beams and Optical components sections first.
